# MPRealEstate — Платформа для Управління Операціями Нерухомості

## Що це за проект?

**MPRealEstate** — це цифрова платформа для спрощення продажу та купівлі нерухомості. Система спрямована на те, щоб поєднати всіх учасників угоди — покупців, продавців, юристів та агентів — в одному місці. Замість розсіяння інформації по електронних листах, SMS та різних додатках, всі беруть участь в структурованому, прозорому та легко відслідковуваному процесі.

Система керує усім циклом угоди: від публікації оголошення про продаж до завершення угоди або розірвання контракту. Кожен учасник бачить актуальний статус, отримує своєчасні сповіщення та має доступ до всієї необхідної документації в одному місці.

## Для кого це призначено?

- **Продавці** — люди, які хочуть продати свою нерухомість
- **Покупці** — люди, які шукають нерухомість та хочуть зробити пропозицію
- **Юристи** — фахівці, які консультують обидві сторони під час угоди
- **Адміністратори системи** — люди, які керують платформою
- **Агенти нерухомості** (в майбутньому) — професіонали, які допомагають покупцям та продавцям

## Що вміє система?

### Для продавців
- Розміщувати новий об'єкт нерухомості з фото, описом, ціною та деталями (площа, кількість кімнат, підвал, гараж тощо)
- Переглядати та керувати всіма отриманими пропозиціями від покупців
- Прийймати або відхиляти пропозиції
- Запланувати та керувати зустрічами для перегляду нерухомості
- Керувати всіма активними угодами та бачити, на якому етапі вони знаходяться
- Запросити юриста для консультацій та перевірки документів
- Завантажувати та зберігати всі документи угоди (акти, розписки, контракти тощо)
- Отримувати сповіщення про важливі подіння та дедлайни
- Видалити оголошення, коли продаж завершено

### Для покупців
- Переглядати список доступної нерухомості на інтерактивній карті
- Шукати та фільтрувати об'єкти за характеристиками (ціна, площа, місцезнаходження)
- Зберігати улюблені об'єкти для пізнішого перегляду
- Запланувати та скасувати зустріч для перегляду нерухомості
- Надіслати пропозицію (пропозицію покупки) для обраного об'єкта
- Вносити гарантійний депозит після прийняття пропозиції
- Керувати своїми активними угодами та бачити їх статус
- Обирати дату умовної позитивної звіту та дату вступу у володіння
- Запросити юриста для полегшення угоди
- Завантажувати та переглядати всі документи угоди
- Запросити розірвання угоди, якщо виникли проблеми
- Отримувати оновлення про прогрес угоди

### Для юристів
- Переглядати угоди, в яких вони задіяні
- Розглядати всю документацію угоди
- Завантажувати та ділитися юридичними документами
- Консультувати обидві сторони через платформу
- Керувати розпорядженнями про розірвання угод

### Для адміністраторів
- Керувати системою та користувачами
- Моніторити всі угоди та операції на платформі
- Отримувати звіти про активність та статистику

## Як виглядає процес угоди?

Угода проходить кілька етапів, на кожному з яких обидві сторони мають конкретні дії:

1. **Розміщення оголошення**
   - Продавець публікує нерухомість з описом, фото та ціною

2. **Пошук та огляд**
   - Покупець переглядає доступні об'єкти на карті та в списку
   - Покупець запланує зустріч для перегляду з продавцем

3. **Пропозиція**
   - Покупець надсилає пропозицію (пропозицію покупки) з запропонованою ціною
   - Продавець розглядає та приймає або відхиляє пропозицію

4. **Гарантійний депозит** (Security Deposit)
   - Після прийняття пропозиції покупець вносить гарантійний депозит
   - Продавець підтверджує отримання депозиту

5. **Умовна позитивна звіт** (Condition Day)
   - Покупець обирає дату, до якої він повинен видалити будь-які умови угоди
   - Продавець підтверджує цю дату
   - До цієї дати покупець може розірвати угоду без втрати депозиту, якщо виявляться серйозні проблеми

6. **День вступу у володіння** (Possession Day)
   - Покупець обирає дату, коли він матиме право вступити у володіння нерухомістю
   - Продавець підтверджує цю дату
   - Це дата закриття угоди

7. **Розірвання угоди** (опційно)
   - Будь-яка сторона може запросити розірвання угоди з причиною
   - Друга сторона відповідає на цей запит (погоджується або відхиляє)
   - Система фіксує цей процес в документах

8. **Завершення**
   - Коли дата вступу у володіння минула, угода вважається завершеною
   - Обидві сторони отримують сповіщення про завершення

## Ролі в системі

### Покупець (Buyer)
Людина, яка хоче придбати нерухомість.

Що вона може робити:
- Переглядати всі оголошення та шукати нерухомість
- Зберігати улюблені об'єкти
- Планувати зустрічі для перегляду
- Надсилати пропозиції для покупки
- Вносити гарантійний депозит
- Встановлювати дати умовної позитивної звіту та вступу у володіння
- Керувати своїми угодами та документами
- Спілкуватися з продавцем та юристом
- Запросити розірвання угоди

### Продавець (Seller)
Людина, яка продає нерухомість.

Що вона може робити:
- Розміщувати нові оголошення про нерухомість
- Редагувати деталі оголошення
- Керувати пропозиціями від покупців (приймати, відхиляти)
- Планувати зустрічі для перегляду з потенційними покупцями
- Встановлювати та підтверджувати дати в угоді (депозит, умовна звіт, вступ у володіння)
- Керувати документами угоди
- Видаляти оголошення
- Спілкуватися з покупцем та юристом
- Відповідати на запити розірвання угоди

### Юрист (Lawyer)
Фахівець, який консультує сторони й забезпечує юридичну безпеку угоди.

Що він може робити:
- Переглядати угоди, в яких він задіяний
- Переглядати всю документацію
- Завантажувати юридичні документи
- Керувати розпорядженнями про розірвання угод
- Консультувати обидві сторони

### Адміністратор (Admin)
Менеджер платформи.

Що він може робити:
- Мати доступ до всіх системних даних
- Керувати користувачами
- Моніторити операції
- Отримувати звіти про активність

## Технології (коротко)

**MPRealEstate** розроблено на сучасному стеку: PHP Laravel (backend), React з TypeScript (frontend), PostgreSQL для даних, Redis для кешування та черг, та розташовується на Docker. Система використовує інтерактивні карти Mapbox для відображення нерухомості та автоматичні сповіщення для оновлення користувачів.
